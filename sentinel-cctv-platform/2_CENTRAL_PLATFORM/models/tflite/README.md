# TFLite AI Models Store

This directory contains the core TensorFlow Lite (TFLite) models used for ANPR edge inference in the GujRaksha platform:

- `plate_detector.tflite` — Vehicle License Plate Bounding Box Detector
- `plate_ocr.tflite` — License Plate Character Recognition OCR Model

Refer to [model_manifest.json](file:///home/fenil/sentinel.gujarat.gov.in/sentinel-cctv-platform/models/tflite/model_manifest.json) for model resolution details.
